# 论坛体小说创作与小红书手绘风出图方法论

本指南定义了「纯正论坛体小说」的文本创作规范与小红书手绘草稿风固定 UI 渲染方法论。当用户要求创作**论坛体 / 树洞体 / 贴吧盖楼体**小说，或要求将论坛体导出为小红书图片时，严格执行本指南。

---

## 一、纯正论坛体文本创作四大核心规范

### 1. 100% 纯盖楼结构（零帖外旁白、零小说式描述）
- **从第一行到最后一行，全篇必须在同一个论坛帖（`0L 主楼` 至 `XXL 封帖`）中通过盖楼回复推进**。
- **严禁出现任何帖外旁白、场景描写、心理独白或小说叙事段落**；也不要插入浮夸生硬的“全塔/全服金色广播弹窗”。所有剧情冲突与结局，全部通过楼主回帖、层主吃瓜、知情人侧面爆料与正主小号下场自然呈现。
- **标准 Markdown 楼层格式**（与渲染脚本 100% 咬合）：
  ```markdown
  **【版块名称 > 子版块名称】**

  **标题：【求助】帖子标题内容**

  ---

  **【0L 楼主昵称（楼主）】**

  主楼正文段落……

  ---

  **【1L 匿名用户】**

  回帖内容……
  ```

### 2. 极简口语 + 侧面留白拼图（严禁镜头级细节描写）
- **去小说腔**：发帖人和回帖人只用最简单直白的日常口语陈述**表面现象与结果**，绝不写小说式的镜头细节描写或修辞渲染。
- **侧面拼图手法**：楼主只陈述自己看到的表象（往往带着视角局限或迟钝误解），由楼下的吃瓜网友与知情层主从侧面补充信息，让读者在楼层互动中自己拼凑出完整真相与人物情感张力。

### 3. 全员匿名与零真名暴露（代称化语境）
- 在真实的匿名树洞帖里，**通篇下来绝不爆出任何一个角色的真名或姓氏**。
- **ID 规范**：
  - **楼主**：固定一个符合人设的昵称，如 `柑橘软糖（楼主）`。
  - **正主/关键角色小号**：使用系统默认风格或带数字纪念意义的代号（如 `用户0719`），发言简短克制。
  - **其余所有围观群众与知情同事**：ID 统一为 `匿名用户`（知情同事多次出现时可在正文开头写「我是22楼！」认领身份）。
- **人物指代**：楼内统一使用代称交流（如「楼主」「顶楼那位执行官」「那位活阎王」「匹配中心那位评审官」）。

### 4. 自然篇幅，不为凑字数注水
- 纯论坛体依赖高密度的信息差反转与精炼互动，无需套用长篇字数硬指标，保持语言简练、节奏明快即可。

## 二、小红书「手绘草稿手账风」固定 UI 渲染方法论

配套脚本位置：
- 技能内置：`{skillBaseDir}/scripts/render_xhs_forum.js`
- 工作区快捷入口：`./工具/生成小红书论坛体图片.js`

### 1. 手机端原生大字护眼排版
- **原生逻辑视口**：画布严格采用 iPhone 逻辑宽度基准 `375 × 500` + `deviceScaleFactor: 3` 超清渲染（输出 `1125 × 1500 px`，标准小红书 `3:4` 竖版比例），使 CSS 字号 1:1 对应手机屏幕真实字号（`pt`）。
- **大字号与全宽对齐**：正文字号默认设为 **`15.5pt`**（每行仅 19～21 个汉字，加 `0.12px` 微描边防压缩发虚）；取消正文左侧头像缩进浪费，采用全宽左对齐，确保在小红书信息流里不点大图也能轻松阅读。
- **自然段级零截断分页**：通过无头浏览器实测每个楼层表头与每一自然段的真实 DOM 高度。短楼层整层同页；长楼层在页尾剩余空间充足时自动按自然段跨页切分，并在下一页顶部自动生成 `#XXL (续)` 标识，既不截断文字，也不在页尾留大块空白。

### 2. 去 AI 感 · 手绘草稿手账风视觉设计
- **摒弃 AI 模板套路**：彻底去除渐变光泽胶囊按钮、高斯模糊悬浮阴影与系统默认 Emoji。
- **核心手绘视觉元素**：
  - **方格草稿本底纹**：暖色调方格手账纸背景 + 顶部手写虚线眉栏。
  - **SVG 钢笔微抖动线框**：通过全局 SVG `<feTurbulence>` + `<feDisplacementMap>` 滤镜（`#sketch-wobble`）单独作用于卡片边框、和纸胶带与印章层，呈现真实钢笔手绘的不规则线条感，而文字层保持 100% 清晰锐利。
  - **错位马克笔硬阴影**：卡片右下方采用手账本平涂错位硬色块阴影，配合顶部半透明斜纹手绘和纸胶带（Washi Tape）。
  - **荧光笔半涂抹高亮**：正文中所有 `「……」` 关键台词自动渲染为马克笔半高涂抹高亮效果。
  - **简笔画涂鸦头像与印章**：内置纯钢笔手绘简笔画头像（楼主脸红小柑橘、男主小号速写黑豹、匿名网友 4 款简笔画吃瓜小人自动轮换）与倾斜手绘印章标签（仅楼主显示 `[楼主]`、新注册特殊小号显示 `[刚注册]`，`匿名用户` 后面绝不挂载任何身份/部门 tag）。

### 3. 多色系自选与随机生成引擎
默认采用 **暖杏甜橘（`warm-orange`）**，同时支持 7 套预设色系、随机生成色系与任意色号自定义：

| 命令参数 | 色系说明 |
| :--- | :--- |
| `--theme=warm-orange` | **暖杏甜橘**（默认，温暖手账橘调） |
| `--theme=mist-blue` | **雾凇冰蓝**（冷白钢笔速写风） |
| `--theme=rose-quartz` | **微醺烟粉**（干枯玫瑰甜宠风） |
| `--theme=matcha-sage` | **竹影青提**（森系水彩护眼风） |
| `--theme=taro-purple` | **暮山香芋**（灰紫悬疑手札风） |
| `--theme=caramel-latte` | **焦糖拿铁**（复古牛皮纸风） |
| `--theme=berry-wine` | **浆果红酒**（复古红黑手账风） |
| `--random` | **随机生成色系**（基于色彩算法生成全新手绘配色，并输出 `--hue=角度` 供复现） |
| `--color=#HEX` 或 `--hue=角度` | **自定义任意颜色**（输入任意色号自动推算全套草稿纸、马克笔、阴影与暗色卡） |

### 4. 「先预览 1 张，确认后再全量生成并同步至私密图库」工作流铁律（必守）
- **论坛体图片统一存放与 GitHub 私密仓库归档规则**：
  - 所有论坛体小说生成的小红书图片（含 `00-封面.png`、`01.png ~ XX.png` 与 `preview.html`），**统一存放在本地私密图库仓库 `./小红书论坛体图库/{小说名称}/` 对应的文件夹下**（不再散落在 `./小说/{小说名称}/小红书图片/` 下）。
  - 该目录已绑定 GitHub 私密仓库：`https://github.com/Kx-Chen-99/xhs-forum-images.git`（分支：`main`）。
- **两步预览与自动上传流程**：
  1. **第一步（快速预览）**：先带 `--first-only`（或 `--page=N`）参数运行脚本，仅生成 1 张预览图展示给用户确认效果（单页预览不会触发 git push）：
     ```bash
     node {skillBaseDir}/scripts/render_xhs_forum.js "./小说/[小说名称]/[小说名称].md" --theme=warm-orange --first-only --with-cover
     ```
  2. **第二步（确认后全量导出并自动上传私密仓库）**：待用户明确表示确认满意后，去掉 `--first-only` 运行全量生成；脚本会自动将全套图片输出至 `./小红书论坛体图库/[小说名称]/`，并自动执行 `git add`、`git commit` 与 `git push origin main` 上传至 GitHub 私密仓库 `Kx-Chen-99/xhs-forum-images`：
     ```bash
     node {skillBaseDir}/scripts/render_xhs_forum.js "./小说/[小说名称]/[小说名称].md" --theme=warm-orange --with-cover --push
     ```
